THE 87TH CLUB — BRAND ADVANCEMENT OS
MASTER BUILD PROMPT · v2 (paste this into Arena AI to build/rebuild it)
=====================================================================

Build a real, functional, private-first, AI-native creative operating system
called THE 87TH CLUB — BRAND ADVANCEMENT OS. A clothing/fashion brand is taken
through eight Brand Advancement Outcomes, and the brand must VISIBLY and
STATICALLY get better as each outcome is completed. Every feature in the OS is
a TOOL that exists only to finish one of the eight outcomes. Nothing else.

THE ACCEPTANCE EXPRESSION (mean this literally, do not decorate it):
"LOGIN → NEW PROJECT → ADD BRAND MATERIALS → AI ANALYSIS → OUTCOME 01 →
OUTCOME 02 → … → OUTCOME 08 → TEST → FINAL BRAND ADVANCEMENT PACKAGE."
The user should never have to think about what they're doing. It should be
SEQUENTIAL, hand-holding, and obvious. From the moment they log in they add
what they have, the OS tells them what it found, what it would change, what it
created, what to approve, and what's next — until all eight outcomes are done
and the brand is measurably better.

1 · THE USER JOURNEY (LOADER / PROGRESS)
=====================================================================
- Show a SINGLE, always-visible "BRAND ADVANCEMENT" journey at the top of the
  app: 01 → 02 → 03 → … → 08, with the current outcome highlighted and a live
  overall percentage filling as work is completed.
- It starts near 0% (e.g., 15% after login) and visibly advances as each
  outcome is finished. It must be REAL (driven by actual database state), not a
  fake animation. Progress persists and is restored on reopen.
- Every screen shows: current outcome, current step, % complete, completed /
  pending / skipped items, AI findings, recommendations, created outputs,
  tests, and the single next action.
- The user can jump between outcomes while dependencies and status are kept.
